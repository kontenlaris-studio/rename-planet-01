One funny new name for a planet in our solar system, plus the why, in a
single line under 200 characters — an entry for the make.fun bounty
[Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369).

> Rename Neptune "The Last Email": 16-hour days, 165-year years, and it
> still has not replied to the sun since 1846.

Run it:

```sh
python3 main.py
```

It prints the line and writes it to `/output/entry.txt`.
